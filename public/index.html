Real device protocol

Trackers connect to the built-in IPS server on TCP port 20332 (#L# login, #D# data, #SD# messages, #P# keep-alive) and receive commands back over the same link. An HTTP ingest endpoint is available for gateways.

Monitoring built for real fleets

Unit tree with status colours, live map, track playback with a timeline, trips / parkings / idle blocks, geofence enter-exit events, notification rules (speed, ignition, SOS, fuel theft, idling, power cut, offline, service due).

Reports you can hand to a client

Unit summary, trips, parkings, activity, geofence visits, events, speed violations, fuel fillings & drainings, engine hours, mileage, drivers and maintenance — with charts, totals, CSV export and a printable layout.

Multi-account and roles

Accounts (resources) with their own units, users, geofences and rules. Roles: super admin, account admin, operator and viewer — the viewer can be limited to specific units, which is how you give a client read-only access.

No dependencies, no build step

PHP 8 + MySQL/MariaDB + vanilla JavaScript. The map uses Leaflet when it can be downloaded and falls back to a built-in canvas map so the console still works fully offline.

Tools included

tools/simulator.php emulates a device and streams live positions, tools/gen_history.php creates demo history and tools/api-test.php runs an end-to-end API test suite.

Quick start

# 1. serve the console (Apache/XAMPP also works — .htaccess is included)
php -S 127.0.0.1:8099 -t "C:\path\to\kivu-tracker" "C:\path\to\kivu-tracker\tools\php-router.php"

# 2. create the database + demo fleet (once)
php install.php --fresh

# 3. start the Wialon IPS device server
php php/tracker.php --verbose

# 4. stream a live track from the bundled device simulator
php tools/simulator.php 356938035643811 --minutes=5 --interval=5

# 5. verify everything end to end
php tools/api-test.php http://127.0.0.1:8099
